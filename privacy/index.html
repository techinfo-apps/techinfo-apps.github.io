Privacy Policy — Muse-YouTube

Last updated: November 26, 2026

What this tool is

Muse-YouTube is a small, private tool used only by the owner of the YouTube channel technology information. It is not a public product, it has no sign-up, and it is never offered to other users. The tool runs on the owner's own server and connects to the owner's own Google account.

What it does with the YouTube API

Through the YouTube Data API and YouTube Analytics API, and only against the owner's own channel, the tool:

  • reads channel statistics (subscriber counts, view counts, and similar aggregate numbers);
  • reads lists of the channel's own videos and comments for moderation review;
  • uploads, updates, and deletes the owner's own videos, captions, and thumbnails.

Data we access and store

The tool accesses only the channel owner's own data. The only items stored are the OAuth tokens needed to keep the tool connected, and small local logs of the statistics it fetched. Everything is stored on the owner's own private server. The tool does not collect personal data from viewers, subscribers, or any other third party.

No sharing, no selling

Data obtained through the YouTube API is not sold, not shared with third parties, not used for advertising, and not transferred to anyone else. There are no analytics or tracking services involved.

YouTube API Services and Google policies

This tool uses YouTube API Services. Its use of YouTube data is governed by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access is granted only by the channel owner to their own account. The owner can revoke the tool's access at any time from the Google Account permissions page: myaccount.google.com/permissions. Revoking access immediately stops the tool from reaching the account, and the stored tokens are then deleted.

Data deletion and contact

Because the tool only ever holds the owner's own data, there is no third-party data to delete. For any question about this policy, or to request deletion of the locally stored tokens and logs, contact: techinfor404@gmail.com.
