文字稿

手工排一千個項目，最多要比較將近五十萬次。這個辦法，不到一萬次。竅門是：不要一口氣排整條清單。先對半拆，再對半拆，直到每一塊都只剩一個項目。然後再按順序拼回去。今天要講：合併排序。

先看關鍵的一步：這裡有兩排，都已經排好了。比一比兩排最前面的項目，拿走比較小的，再重複。每比較一次，就往結果裡放進一個項目。一排拿空了，另一排剩下的直接滑進去。八個項目，最多比較七次。

再看整個辦法。把八個項目拆成兩半，再拆成四份，最後拆成一個一個。只有一個的，本來就是排好的。然後一層層往上合併：先兩個一組，再四個一組，最後八個全部合起來。這就是分治法：把一個大問題拆成同樣的小問題，分別解決，再把答案合起來。

為什麼快？每合併一層，每個項目都只碰一次：大約 n 步。八個項目對半拆到剩一個，只要三層。這就是 log₂ n。所以總共大約是 n 乘上 log n。一千個項目，不到一萬次比較，而不是五十萬次。

代價是記憶體：合併需要另外一排，大小和原來那排一樣。但同樣的想法，還能排連記憶體都放不下的資料：一次只排一小段，排好就寫回硬碟，然後把排好的幾段合併起來，每一段只讀進一點點。這就叫外部排序。

合併排序：拆到不能再拆，再合併起來，永遠是 n log n 的時間。下一集，有一種實際上通常更快、而且不需要多一排的排序：快速排序。我們下集見。
