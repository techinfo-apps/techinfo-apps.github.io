ナレーション全文

1000個を手作業で並べ替えると、最大で50万回近い比較が必要でした。この方法なら、1万回もかかりません。秘訣は、リスト全体を一度に並べ替えないこと。半分に分け、さらにその半分に分け、どの部分も1個だけになるまで続けます。そして、その部分を順番どおりに組み合わせて戻します。今日はマージソートです。

まずは大事な操作から。ここに、すでに並べ終えた2つの列があります。2つの列の先頭どうしを比べて、小さいほうを取り出し、これを繰り返します。比較するたびに、結果に1個ずつ入っていきます。片方の列が空になったら、もう片方の残りはそのまま入ります。8個なら、比較は多くても7回です。

では、方法の全体です。8個を半分に、さらにその半分に、最後は1個ずつに分けます。1個だけのものは、もう並べ終わっています。次に、下から順に合わせていきます。2個ずつ、4個ずつ、最後に8個全部です。これが分割統治法です。大きな問題を、同じ形の小さな問題に分けて、それぞれ解き、答えを組み合わせます。

なぜ速いのでしょう？マージの1段ごとに、すべての要素に1回ずつ触れます。およそ n ステップです。そして、8個を1個になるまで半分にしていくのに、必要なのはたった3段です。これが log₂ n です。ですから、全体ではおよそ n かける log n。1000個なら、比較は1万回未満で済みます。50万回ではありません。

代償はメモリーです。マージには、元の列と同じ大きさの、もう1つの列が必要になります。でも、同じ考え方で、メモリーにまったく収まらない大きなデータも並べ替えられます。ひとまとまりずつ並べ替えて、ディスクに書き戻し、次に、並べ終えたまとまりをマージします。それぞれから、少しずつだけ読み込みます。これが外部ソートです。

マージソート。簡単になるまで分けてから、マージする。いつでも n log n の時間です。次回は、実際にはたいてい、さらに速くて、余分な列もいらない並べ替えです。クイックソート。また会いましょう。
