文字稿

你按下一個鍵。幾毫秒之後，那個字母就出現在螢幕上。可是處理器當時正忙著，替別的事情執行數十億條指令。那它是怎麼發現的？今天要講：CPU 怎麼跟鍵盤、螢幕和硬碟溝通。匯流排（bus）、輪詢（polling）、中斷（interrupt），還有 DMA。

CPU、記憶體和各種裝置，由一組共用的線路連在一起，這組線路叫作匯流排（bus）。位址線傳送位址，說明正在跟誰說話。資料線傳送資料本身。還有控制線，指示是讀取還是寫入。每個裝置都有幾個自己的暫存器：一個說明它有沒有新消息，一個存放消息本身。CPU 讀取它們，就像讀取記憶體位址一樣。

所以最簡單的做法就是：一直問。有按鍵嗎？沒有。現在呢？沒有。現在呢？這就叫輪詢（polling）。這樣行得通，但很浪費時間。處理器檢查了成千上萬次，而幾乎每次的答案都是「沒有」。

比較好的做法：讓裝置自己開口。一按下按鍵，鍵盤，或是負責照看它的那顆晶片，就會在中斷線上發出一個訊號。CPU 先做完手上這條指令，把自己進行到哪裡存起來，也就是程式計數器和暫存器，然後跳到一個叫作中斷處理程式（interrupt handler）的小程式。處理程式讀取按下的鍵，交給作業系統，然後 CPU 就從剛才停下的地方接著做，彷彿什麼事都沒發生過。不必浪費時間去問。CPU 只有在真的有事要做的時候，才會停下來。

但如果是要把一整個檔案從硬碟搬進記憶體呢？要是每個位元組都經過 CPU 來複製，它就得忙上好久好久。所以有一個叫作 DMA 控制器的幫手，自己負責複製，直接從裝置搬進記憶體，而 CPU 就去做別的工作。傳輸完成後，它只送出一次中斷：你的資料準備好了。

總結一下：裝置掛在匯流排上，輪詢是一遍又一遍地問，中斷讓裝置自己開口，而 DMA 不經過 CPU 就能搬動大量資料。電腦的每個部分，我們現在都認識了。下一集是這一季的最後一集：跟著一次按鍵，走遍整台機器。我們下集見。
