文字稿

這八個開關，能把兩個數加起來。五，和三。撥、撥、撥、撥……燈亮出來的是八。沒有晶片，沒有程式碼，只有開關，還有一個最後才會打開的盒子。看完這一集，你就會清清楚楚知道裡面是什麼。

我們從最簡單的電路開始：一顆電池、一條導線、一盞燈，還有一個開關。合上開關，電流就繞著電路流一圈，燈亮了。我們把這叫作 1。打開開關，電流就停了，燈熄了。這就是 0。一個開關只能表示兩件事：開或關，1 或 0。這一個「是或否」，叫作位元（bit），是電腦能儲存的最小資訊單位。電腦裡的每一張照片、每一個字、每一款遊戲，都是用這樣的位元一個一個組成的。

現在加上第二個開關，和第一個串在一起。我們叫它們 A 和 B。只合上 A……沒反應。只合上 B……還是沒反應。兩個都合上，燈就亮了。電流得先通過 A，再通過 B。只要有一個是斷開的，路就斷了。我們把四種情況寫成表格。0 和 0 得 0，0 和 1 得 0，1 和 0 得 0，1 和 1 得 1。這就是及閘（AND）。只有 A 和 B 都是 1 時，輸出才是 1。

現在把兩個開關並排接，電流就有兩條路可以通到燈。合上 A，燈亮了。換成合上 B，也亮。兩個都合上，還是亮。只有兩個都打開時，燈才會熄滅。這就是或閘（OR）：A 是 1，或 B 是 1，或兩個都是 1，輸出就是 1。

再來一個。這個按鈕是反著接的：不按的時候是通的。所以燈本來是亮的……按下按鈕，燈就熄了。這就是反閘（NOT）。輸入什麼，輸出的就是相反的。1 變成 0，0 變成 1。

到目前為止，開關都是我們自己撥的。真正的電腦裡，沒有人去碰它們。撥開關的是電。電晶體是一個很小的開關，當第三條線上有訊號傳來，它就會合上。這一下，一切都不一樣了。因為現在，一個閘的輸出，可以去撥動下一個閘的開關。閘可以驅動其他的閘。這表示我們能把它們一個接一個串起來，組成越來越大的電路。為了讓圖畫起來簡單，工程師為每種閘設計了專屬的符號。這是及閘，這是或閘，這個帶小圓圈的小三角形是反閘。現代的晶片裡塞了幾十億個這樣的開關，而每一個每秒鐘都能開關幾十億次。不過在建造任何大東西之前，我們得先學會怎麼用它們來數數。

我們平常是用十進位來數數。最右邊那一欄數個位。數過九，就回到零，並往下一欄進一：十位。所以兩百五十三，就是兩個百、五個十、三個一。現在想像一下，你只有兩個數字：0 和 1。開關能表示的，就只有這兩個。規則是一樣的。最右邊那一欄數個位。只不過數過 1 就進位，而不是數過 9。所以每一欄的價值，都是右邊那一欄的兩倍：1、2、4、8。我們用四盞燈來數數。0。1。這時第一欄滿了，所以要進位：2 是 1、0。3 是 1、1。4 是 1、0、0。一路數下去，四盞燈可以從 0 數到 15。5 是 4 加 1：0、1、0、1。3 是 2 加 1：0、0、1、1。這正是一開始那些開關擺出來的樣子。這種數法叫作二進位。

現在來做加法。我們從最小的加法開始：一個位元加一個位元。只有四種情況。0 加 0 是 0。0 加 1 是 1。1 加 0 是 1。而 1 加 1 等於 2，用二進位寫成 1、0。我們這一位寫下 0，然後把 1 進位。所以每個一位元的加法都有兩個輸出：和，還有進位。看進位那一欄：0、0、0、1。這個模式我們見過，它就是及閘。再看和那一欄：0、1、1、0。只有兩個輸入不一樣時，它才是 1。

我們還沒有這樣的閘，不過可以用手上這三種閘組合出一個來。先取 A 或 B。只要至少有一個輸入是 1，它就是 1。然後再用及閘和反閘，把「兩個都是 1」的情況擋掉。結果只有在兩個輸入不一樣時才是 1。這叫作互斥或（XOR），它也有自己的符號。把一個互斥或閘和一個及閘並排，餵給它們同樣的兩個位元，就能得到和與進位。這就是半加器。

為什麼只算「半個」？想想你在紙上怎麼加比較大的數。你從最右邊開始，加完一欄，再把進位帶到下一欄。所以從第二欄起，每一欄要加三個數：A、B，還有進來的進位。半加器只能加兩個數。所以我們用兩個半加器。第一個半加器加 A 和 B。第二個半加器，把這個結果再加上進來的進位。只要它們其中一個產生了進位，我們就要往下一位送出進位。一個或閘就能搞定。兩個半加器加一個或閘，就是全加器。輸入三個位元，輸出一個和與一個進位。

現在把四個全加器排成一列，一欄一個，再把每一個的進位輸出，接到下一個的進位輸入。還記得一開始那個盒子嗎？我們來打開它。它裡面一直都是這個：一排四個全加器。再算一次 5 加 3。第一欄：1 加 1。和是 0，進位 1。進位往左傳，就像接力賽裡的接力棒。0 加 1，再加進位：和是 0，進位 1。下一欄也是一樣。直到最後一欄：0 加 0，再加進位，得到 1。燈亮出來是 0、1、0、0、0。這就是 8。真正的電腦做的是同一件事，只是用 64 欄，而不是 4 欄。原理完全沒變。

我們回頭看看。一個開關給了我們一個位元。串起來、並起來的開關，給了我們閘。閘去撥動閘，給了我們加法器。我們一步都沒有離開「開」和「關」的世界。但有個問題。這個電路裡，哪裡都沒有負號。那麼，電腦要怎麼做減法，甚至怎麼儲存負數呢？那就是下一集的內容。我們下集見。

盒子裡有什麼？四個小加法器，把進位從右往左傳。所有電腦都是這樣做加法的。完整的故事，從一個開關說起。

四盞燈可以一路數到 15。看看是怎麼數的。這就是二進位，每一台電腦都是這樣數數的。
