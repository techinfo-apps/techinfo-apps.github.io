文字稿

这八个开关能把两个数加起来。五，和三。拨、拨、拨、拨……灯亮出来的是八。没有芯片，没有代码，只有开关，还有一个最后才打开的盒子。看完这集，你会清清楚楚地知道里面是什么。

从最简单的电路开始：一节电池、一根导线、一盏灯、一个开关。合上开关，电流绕着回路流一圈，灯亮了。我们把这叫作 1。断开开关，电流停了，灯灭了。这就是 0。一个开关只能说两件事：开或关，1 或 0。这一个“是或否”，叫作一位（bit），是电脑能存的最小的一份信息。电脑上的每张照片、每个字、每个游戏，都是用这样的一位一位搭起来的。

现在加第二个开关，跟第一个排成一串。我们叫它们 A 和 B。只合上 A……灯不亮。只合上 B……还是不亮。两个都合上，灯亮了。电流得先过 A、再过 B，哪一个断开，路就断了。把四种情况写进表里：0 和 0 得 0，0 和 1 得 0，1 和 0 得 0，1 和 1 得 1。这就是“与门”：只有 A 和 B 都是 1，输出才是 1。

现在把两个开关并排接，电流就有两条路通到灯。合上 A，灯亮；换成合上 B，也亮；两个都合上，还是亮。只有两个都断开，灯才会灭。这就是“或门”：A 是 1，或者 B 是 1，或者两个都是，输出就是 1。

再来一个：这个按钮是反着接的，不按的时候是通的。所以灯本来亮着……按下按钮，灯反而灭了。这就是“非门”：进去什么，出来就是反的。1 变 0，0 变 1。

到现在为止，开关都是我们自己拨的。真正的电脑里，没有人去碰它们。拨开关的是电。晶体管就是一个很小的开关，第三根线上来了信号，它就合上。这一下就不一样了：一个门的输出，可以去拨下一个门的开关。门能带动别的门，所以我们能把它们一个接一个连起来，搭成越来越大的电路。为了画起来简单，工程师给每种门一个符号：这是与门，这是或门，这个带小圆圈的三角是非门。一颗现代芯片里有几十亿个这样的开关，每个每秒能开关几十亿次。不过在搭大东西之前，得先学会用它们数数。

我们平时按十来数：最右边一位数个数，过了九就回到零，往左边一位进一，那一位是十。所以二百五十三，就是两个百、五个十、三个一。现在想象一下，只有两个数字，0 和 1。开关能表示的就只有这两个。规则一样：最右边一位数个数，只不过过了 1 就进位，而不是过了 9。所以每一位都是右边那位的两倍：1、2、4、8。用四盏灯数数：0、1，第一位满了，进位，2 就是 1 0；3 是 1 1；4 是 1 0 0。一直数下去，四盏灯能从 0 数到 15。5 是 4 加 1：0101。3 是 2 加 1：0011。这就是开场那些开关摆出来的样子。这种数法叫二进制。

现在来做加法。先从最小的加法开始：一位加一位。只有四种情况：0 加 0 得 0，0 加 1 得 1，1 加 0 得 1。1 加 1 等于 2，二进制写成 1 0：这一位写 0，把 1 进到下一位。所以一位加法有两个输出：和，还有进位。看进位那一列：0、0、0、1。这个样子我们见过，就是与门。再看和那一列：0、1、1、0。只有两个输入不一样时，它才是 1。

我们还没有这样的门，但能用手上这三种拼一个出来。先取 A 或 B：至少有一个是 1，它就是 1。再用与门和非门，把“两个都是 1”的情况挡掉。结果只在两个输入不一样时是 1。这叫“异或”（XOR），它也有自己的符号。把一个异或门和一个与门并排，喂它们同样的两位，就得到了和与进位。这叫半加器。

为什么只算“半”个？想想你在纸上是怎么加大一点的数的。从最右边开始，加完一列，把进位带到下一列。所以从第二列起，每一列要加三个数：A、B，还有进来的进位。半加器只能加两个，所以用两个半加器。第一个半加器加 A 和 B，第二个把结果再和进来的进位相加。两个里面只要有一个产生了进位，就往下一位送进位，一个或门就够了。两个半加器加一个或门，就是全加器：进去三位，出来和与进位。

现在把四个全加器排成一排，一列一个，每个的进位输出接到下一个的进位输入。还记得开场那个盒子吗？我们打开它。里面一直就是这个：一排四个全加器。再算一次 5 加 3。第一列：1 加 1，和是 0，进位 1。进位往左传，像接力赛里的接力棒。0 加 1，再加进位：和是 0，进位 1。下一列也一样。直到最后一列：0 加 0 再加进位，得 1。灯亮出来是 0 1 0 0 0，就是 8。真正的电脑用 64 列，而不是 4 列，道理完全一样。

回头看一下：一个开关给了我们一位；串起来、并起来的开关给了我们门；门去拨门，就有了加法器。我们一步都没离开过“开”和“关”。可是有个问题：这个电路里哪儿都没有负号。那电脑怎么做减法，又怎么存一个负数？这就是下一集的内容，下集见。

盒子里是什么？四个小加法器，把进位从右往左传。所有电脑都是这样做加法的。完整的故事，从一个开关讲起。
