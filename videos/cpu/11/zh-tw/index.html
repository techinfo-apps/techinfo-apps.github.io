文字稿

看看上一集我們搭好的所有部件。每一步，它們裡面都有數十個小開關，必須撥成完全正確的模式。載入這個暫存器，不要載入那個。做加法，不要做減法。讀取記憶體，不要寫入。誰來決定？今天，我們來認識控制單元。

每個部件都有控制輸入：有的線說「現在載入」，有的線負責選擇加法或減法。我們的小 CPU 有八條。把它們的 1 和 0 並排寫下來，就是一個控制字。擷取時，控制字永遠一樣：讀取記憶體、載入指令暫存器，再把程式計數器加 1。執行 ADD 時：叫 ALU 做加法，再把結果載入暫存器。每條指令的每一個步驟，都有自己的控制字。

控制單元的工作，是在正確的時刻產生正確的控制字。它看三樣東西：運算碼、現在進行到哪一步，還有旗標。步驟來自一個小小的計數器，依序數著擷取、解碼、執行，每來一條新指令就從頭開始。

經典的做法有兩種。第一種叫硬佈線：先想清楚每條控制線的邏輯，再直接用閘搭出來。例如「載入暫存器」這條線，在執行這一步時，只要運算碼是載入、加法或減法，就會打開。三個及閘（AND）和一個或閘（OR）。硬佈線控制很快。但它是一團固定的閘，要改一條指令，就得重新設計電路。

第二種是微程式控制：把每一個控制字都存在控制單元內部的一小塊記憶體裡，每條指令的每一步佔一列。運算碼和步驟合起來是一個位址。控制單元只要讀出那一列，裡面的位元就成了控制線。這是一段用來執行程式的小程式，叫作微碼。要加入複雜的指令，只要多加幾列就行了。它比較慢，因為每一步都要讀一次記憶體。但設計起來容易得多，而且有些處理器在晶片賣出之後，甚至還能更新。

現代的處理器兩種都用：簡單的指令走快速的硬佈線邏輯，少見的複雜指令則退回到微碼。

總結一下：控制單元把每個運算碼和步驟變成控制字，要嘛用閘算出來，要嘛從一小塊存放微碼的記憶體裡讀出來。可是目前每條指令都要走好幾步，其中一個部件在工作時，大多數部件都閒著。下一集：像生產線一樣的訣竅，叫作管線化。我們下集見。
