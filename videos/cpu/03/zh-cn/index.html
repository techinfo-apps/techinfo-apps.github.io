文字稿

两个数进去：五和一。看答案。加：六。减：四。与：一。或：五。同样两个数，四个不同的答案。唯一变了的，就是这个小旋钮。今天，我们来搭它背后的电路。

到现在，我们有一台也会做减法的加法器，由一根控制线决定做哪个。可电脑要做的不止这些：要对一整排比特做与、做或，还要比较大小。

对一排比特做与很简单：四个与门并排，一列一个。五是 0101，一是 0001。一列一列做与，得到 0001。换成四个或门，同样的输入得到 0101。现在我们有三套电路，看着同样两个数，各有各的答案。得有个办法挑一个出来。

想象一个铁路道岔：两条轨道进来，一条出去，一根拉杆决定哪条轨道能通过。信号也能做一个同样的东西，叫“多路选择器”，简称 mux。两个输入 A 和 B，一个输出，还有一根选择线 S。S 是 0，输出照抄 A；S 是 1，就照抄 B。拆开看，里面就是我们认识的门：一个与门只在 S 是 0 时放 A 过去，因为 S 先经过了一个非门。另一个与门只在 S 是 1 时放 B 过去。一个或门把两条路并起来。每次只有一条路是通的，所以出来的就是我们选中的那个输入。要从四个里挑一个，就把选择器叠起来：两个选择器各在一对里挑，第三个在两对之间挑。这样就要两根选择线。两位有四种组合：00、01、10、11，正好一个输入一个。

选择器有个近亲，叫“译码器”。它反过来：两位输入，四根输出线。永远只亮一根：就是你输入的那个号码。00 亮第 0 根，11 亮第 3 根。每根输出就是一个与门，想要哪位是 0，就在那位上先接一个非门。记住这个译码器。再过几集，它要在内存里从几百万个格子中挑出一个。

再来看比较。五等于一吗？比一大吗？用不着新电路，做个减法就行。五减一是四。不是零，所以不相等；结果也不是负的，所以五比较大——只要没有溢出。要看结果是不是零，把四位结果都接到一个或非门上：就是或门后面接一个非门。四位全是 0，它才出 1。那盏灯叫“零标志”。结果最左边一位表示正负，那是“负数标志”。加上上一集的进位和溢出标志，这几盏小灯就把答案描述清楚了：是不是零、是不是负数、是不是装不下。先减，再看标志。电脑就是这样比较大小的。

现在把它们拼起来。A 和 B 同时进三个部件：加减法器、一排与门、一排或门。三个部件每次都同时在算，各出一个答案。每一列一个四选一，挑哪个答案出去；它的两根选择线就是“运算码”。00 是加；01 是减，这一位同时接到减法控制线上；10 是与；11 是或。标志灯放在旁边，描述出来的是什么样的答案。工程师把这一整块画成一个上面带缺口的形状：ALU，算术逻辑单元。真正的运算器操作更多：移位、异或等等。但道理就是这样：每个部件都在算，选择器挑出答案。回到开场的旋钮。五和一。加：六。减：四。与：一。或：五。

我们的运算器答得飞快，可它什么都记不住：输入一变，原来的答案就没了。要搭一台电脑，还得有会记东西的电路，过几集就讲。下一集先看运算器怎么做乘除法，下集见。

同样两个数，转一下旋钮。里面三套电路同时在算，选择器挑出一个答案。这就是 ALU，每颗处理器心里的计算器。

电脑怎么知道五比一大？它做减法。减一下，看看标志灯，这就是比较。
