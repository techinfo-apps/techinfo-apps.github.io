文字稿

兩個數進去：五和一。看看答案。加：六。減：四。及運算：一。或運算：五。同樣兩個數，四個不同的答案。唯一變了的，就是這個小旋鈕。今天，我們來搭它背後的電路。

到目前為止，我們有一台也會做減法的加法器，由一條控制線決定做哪一種。但電腦要做的不只這些。它要對一整排位元做及運算和或運算，還要比較數字的大小。

對一排位元做及運算很簡單：四個及閘並排，一欄一個。五是 0、1、0、1。一是 0、0、0、1。一欄一欄做及運算，得到 0、0、0、1。換成四個或閘，同樣的輸入會得到 0、1、0、1。現在我們有三套電路，看著同樣兩個數，各有各的答案。得想個辦法挑出一個來。

想像一個鐵路道岔：兩條軌道進來，一條出去，一根拉桿決定哪一條軌道能通過。訊號也能做出一個同樣的東西，叫作多工器，英文簡稱 mux。兩個輸入 A 和 B，一個輸出，還有一條選擇線 S。S 是 0，輸出就照抄 A；S 是 1，就照抄 B。拆開來看，裡面就是我們認識的閘：一個及閘只在 S 是 0 時放 A 通過，因為 S 先經過了一個反閘。另一個及閘只在 S 是 1 時放 B 通過。一個或閘把兩條路接起來。每次只有一條路是通的，所以出來的就是我們選中的那個輸入。要從四個輸入裡挑一個，就把多工器疊起來：兩個多工器各在一對裡挑，第三個在兩對之間挑。這樣就需要兩條選擇線。兩個位元有四種組合：00、01、10、11，正好一個輸入對應一種。

多工器有個近親，叫作解碼器。它的方向剛好相反：兩個輸入位元，四條輸出線。恰好只有一條輸出會亮：就是你輸入的那個號碼。00 會亮起第 0 條線，11 會亮起第 3 條線。每一條輸出就是一個及閘，想要哪一位是 0，就在那一位的輸入上先接一個反閘。先記住這個解碼器。再過幾集，它要從記憶體裡好幾百萬個格子中，挑出其中一格。

再來談比較。五等於一嗎？比一大嗎？這不需要新的電路，我們做減法就好。五減一是四。不是零，所以兩者不相等；結果也不是負的，所以五比較大，只要沒有發生溢位。要檢查結果是不是零，就把四個結果位元都接到同一個反或閘（NOR）上：也就是在或閘的輸出端再接一個反閘。只有每一個位元都是 0，它才會輸出 1。那盞燈叫作零旗標。結果最左邊的位元告訴我們正負，那就是負旗標。再加上上一集的進位旗標和溢位旗標，這幾盞小燈就能描述答案：是不是零、是不是負數、是不是太大放不下。先做減法，再看旗標。電腦就是這樣比較大小的。

現在把它們全部拼起來。A 和 B 同時進入三個部件：加減法器、一排及閘，和一排或閘。這三個部件每一次都同時在運作，各自算出自己的答案。每一欄各有一個四選一多工器，挑出哪個答案要輸出。它的兩條選擇線，就是運算碼。00 是加。01 是減：同一個位元也同時接到減法線上。10 是及運算。11 是或運算。旗標則放在一旁，描述剛剛算出來的是什麼樣的答案。工程師會把這整個東西畫成一個形狀，上面帶一個缺口：ALU，也就是算術邏輯單元。真正的 ALU 還有更多運算：移位、互斥或（XOR），等等。但道理就是這樣：每個部件都在計算，由多工器挑出答案。回到我們的旋鈕。五和一。加：六。減：四。及運算：一。或運算：五。

我們的 ALU 答得很快，但它沒有記憶。輸入一變，原來的答案就消失了。要造出一台電腦，還需要會記東西的電路，過幾集就會講到。下一集先看運算器怎麼做乘除法，我們下集見。

同樣兩個數。轉動旋鈕。裡面有三套電路同時在運作，多工器從中挑出一個答案。這就是 ALU，每一顆處理器最核心的計算器。

電腦怎麼知道五比一大？它做減法。做減法，再看旗標。這就是比較。
