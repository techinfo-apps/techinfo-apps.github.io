文字稿

這還是上一集的那台加法器，一個新零件都沒有加。五……再加負三。一撥……燈亮出來的是二。這台加法器會做減法。秘密就在「負三」的寫法裡。我們來看看，那到底是怎麼寫的。

上一集我們搭了這個：一排四個全加器，把進位從右往左傳。它可以把 0 到 15 之間的任意兩個數加起來。

但真實世界的數可以是負的。氣溫可以降到零下，電梯可以下到地面樓層以下。電路裡沒有地方可以寫負號，只有亮或不亮的燈。所以負號本身也得變成一個位元。最直接的想法：拿最左邊那盞燈當作符號。

最左邊的燈熄滅表示正，亮起表示負。其餘三盞燈表示大小。所以正三是 0、0、1、1，負三是 1、0、1、1。看起來很合理，但有兩個問題。第一，零出現了兩次：正零和負零。同一個數有兩種寫法很浪費，也讓比較大小變得很麻煩。第二，用我們的加法器算三加負三，答案應該是零。結果燈卻亮出 1、1、1、0。照符號位元的規則來讀，這是負六。要用這種寫法，就得為負數另外做一整套電路。其實有更好的辦法。

想像一個老式的機械計數器，顯示 0、0、0、0。往回撥一格。它不會停在零，而是繞回到 9、9、9、9。二進位計數器也一樣。從全是 0 往回撥一格，就會變成全是 1。那我們就乾脆把它叫作負一。再往回一格是 1、1、1、0：負二。然後是負三，依此類推。把全部 16 種寫法排成一個圓圈。右半邊是 0 到 7，左半邊是負 1 一路到負 8。你看，每個負數最左邊的位元還是 1。符號燈就這樣白白保留了下來。加法就是在圓圈上順時針走。負三離 0 有 13 步，所以加上它，就是往前走 13 步。在一個只有 16 格的圓圈上，往前走 13 步，正好會落在往回走三步的地方。從三出發，那就是零。

這種寫負數的方法叫作二補數。你用過的電腦，幾乎都是這樣運作的。不需要圓圈也能找出它。有一個兩步驟的做法：把每一個位元翻轉，然後加一。三是 0、0、1、1。把每個位元翻轉：1、1、0、0。加一：1、1、0、1。這就是負三。為什麼這樣可行？任何一個數，加上它翻轉後的樣子，每一欄都會變成 1，而且完全沒有進位。全部是 1 就是負一。所以翻轉後的數，等於負一減去原來的數。再加一，就剛好是原來那個數的負數。那零呢？翻轉成全是 1，加一，就會繞回全是 0。進位從最左邊掉了出去。只剩下一個零。問題解決了。

現在減法就簡單了。A 減 B，等於 A 加負 B。而負 B 就是把 B 翻轉再加一。所以 A 減 B，等於 A，加上翻轉後的 B，再加一。翻轉很容易，那正是反閘做的事。但我們希望這個電路還是能做加法。訣竅在這裡。還記得互斥或閘嗎？如果其中一個輸入是 0，另一個輸入就原樣通過。如果其中一個輸入是 1，另一個輸入出來時就被翻轉了。所以在每一條 B 線上各放一個互斥或閘，再把它們全部接到同一條控制線上。我們叫它「減法」。當「減法」是 0，B 原樣通過，電路做加法。當「減法」是 1，B 的每一個位元都會被翻轉。那「加一」呢？第一個加法器有一個我們一直沒用過的進位輸入。把同一條控制線也接上去。一條線。翻轉和加一，一次完成。五減三。五是 0、1、0、1。三翻轉後是 1、1、0、0。再加上控制線送來的 1。加法器依序接力，結果是 1、0、0、1、0。最左邊多出來的進位直接掉出去，剩下 0、0、1、0。也就是二。一開始，負三是我們用手撥進去的。現在電路自己就會翻轉：四個互斥或閘加上一條控制線，把我們的加法器變成了加減法器。

還有一個陷阱。四個位元只能裝下 16 種寫法：從負 8 到 7。那六加三呢？0、1、1、0 加上 0、0、1、1，得到 1、0、0、1。用二補數來讀，這是負七，不是九。在圓圈上，我們走過了 7，掉過邊界，進到負數那一側。這叫作溢位。解決辦法就是發現它。兩個正數相加，絕不該得到負數。兩個負數相加，也絕不該得到正數。加幾個閘專門盯著這件事，一出現就點亮警示燈：溢位旗標。大多數處理器都有這個旗標。真正的電腦使用 32 位元或 64 位元，所以範圍非常大。32 位元可以超過 21 億。但溢位還是會發生。2014 年，這個網站上有一支影片的觀看次數多到，計數器眼看就要溢位，只好升級成 64 位元。

現在，我們的小電路能做加法和減法，能處理負數，而且當答案放不下時，它也知道。但電腦要做的遠不止加減。它要比較數字。它要對一整排位元做及運算和或運算。一個電路怎麼知道，每一刻該做哪一件工作？下一集：會做選擇的電路。我們下集見。

這個電路只會做加法。看它怎麼做減法。訣竅在於電腦怎麼寫負數：把每一個位元翻轉，再加一。把它加到五上，丟掉多出來的進位，就得到二。幾乎所有電腦都是這樣做減法的。

在四位元的電腦裡，六加三等於負七。原因在這裡。真正的電腦有更多位元，還有一盞叫作溢位旗標的警示燈。
